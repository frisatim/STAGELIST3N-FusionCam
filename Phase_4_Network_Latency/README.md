# Phase 4 - Reseau et latence

Cette phase regroupera les experiences sur l'impact du reseau :

- comparaison RTSP/TCP et RTSP/UDP ;
- simulation de latence, jitter et pertes ;
- mesure de l'impact sur FPS, TAD, TRD et stabilite des alertes.

Les scripts et resultats de cette phase ne sont pas encore consolides dans ce depot.
